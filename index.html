The idea behind the keys

One key locks.
One key opens.

RSA is public-key cryptography. You can publish one key openly while keeping its paired key private. The pair lets people send you protected messages without first sharing a secret password.

For learning and demos. This website is an educational tool. Use established, reviewed software for sensitive or production communication.
01Create a matched pair

Your browser generates a public key and its corresponding private key. The public key can be shared freely; protect the private one.

02Encrypt for the recipient

A sender uses the recipient’s public key. Only the matching private key can recover the message.

03Use RSA and AES together

RSA-OAEP wraps a fresh AES key, and AES-GCM encrypts the message. This hybrid approach handles longer messages while keeping the public-key step small.
